# Notebooks and examples

Seven Jupyter notebooks and a set of runnable scripts ship with the repository. The notebooks are generated by
`scripts/generate_notebooks.py` and executed top to bottom by the slow test suite
(`pytest -m slow tests/docs/test_notebooks.py`); the example scripts are smoke-tested by
`tests/docs/test_examples_smoke.py`. They are tutorials, not validation: see [Validation](validation.md) for the checked
benchmarks.

## Notebooks (`examples/notebooks/`)

| # | Notebook | Level | What it shows |
|---|---|---|---|
| 01 | [`01_quickstart_multi_energy_cosim.ipynb`](https://github.com/dgusain1/energysim/blob/master/examples/notebooks/01_quickstart_multi_energy_cosim.ipynb) | beginner | The `world`, macro versus micro steps, signals, a PV plant with a battery, `Results` access and plots. |
| 02 | [`02_grid_cosim_pandapower_pypsa_opendss.ipynb`](https://github.com/dgusain1/energysim/blob/master/examples/notebooks/02_grid_cosim_pandapower_pypsa_opendss.ipynb) | intermediate | A pandapower distribution feeder coupled with a PyPSA regional network, with kW / MW conversion between them. |
| 03 | [`03_custom_models_and_parametrization.ipynb`](https://github.com/dgusain1/energysim/blob/master/examples/notebooks/03_custom_models_and_parametrization.ipynb) | intermediate | A custom `ModelComponent` (supercapacitor), `Curve1D` / `Surface2D` lookups, an `OperatingStateMachine`, re-parametrizing library models. See [Custom models](custom-models.md). |
| 04 | [`04_building_custom_simulator_adapters.ipynb`](https://github.com/dgusain1/energysim/blob/master/examples/notebooks/04_building_custom_simulator_adapters.ipynb) | advanced | Subclassing `SimulatorAdapter` to wrap an external engine, here a hydraulic network. See [External simulators](external-simulators.md). |
| 05 | [`05_industrial_btm_complex.ipynb`](https://github.com/dgusain1/energysim/blob/master/examples/notebooks/05_industrial_btm_complex.ipynb) | complex | A 24 h behind-the-meter industrial site: PV, battery, CCGT, PEM electrolyzer, hydrogen tank, process steam load. |
| 06 | [`06_vectorized_fleet_aggregation.ipynb`](https://github.com/dgusain1/energysim/blob/master/examples/notebooks/06_vectorized_fleet_aggregation.ipynb) | performance | A 10 000-unit battery fleet advanced in one NumPy step and aggregated. See [Fleets](containers/overview.md). |
| 07 | [`07_green_hydrogen_valley.ipynb`](https://github.com/dgusain1/energysim/blob/master/examples/notebooks/07_green_hydrogen_valley.ipynb) | sector coupling | PEM, alkaline and SOEC electrolyzers, waste heat into a heat pump, hydrogen compression and storage, methanation. |

Running them locally:

```bash
git clone https://github.com/dgusain1/energysim.git
cd energysim
pip install -e ".[all]"          # the simulators and extras the notebooks use
pip install jupyterlab matplotlib
jupyter lab examples/notebooks/
```

## Example scripts (`examples/`)

| Directory | Scenario |
|---|---|
| `microgrid/` | A 24 h prosumer microgrid: dynamic models plus a pandapower grid and CSV weather / demand. |
| `community_microgrid/` | Community microgrid with battery, building envelopes, PV and HVAC under a dispatcher. |
| `mpc_microgrid/` | A residential microgrid dispatched by model predictive control, using all the simulator kinds, including MATLAB / Octave. |
| `ml_grid/` | A 5-bus distribution grid with neural-network load and generation forecasters as simulators. |
| `matlab_cosim/` | Three `.m` function models (heat pump, battery, thermal mass); needs MATLAB or Octave. |
| `industrial_btm/` | The industrial site of notebook 05 as a script. |
| `optimal_dispatch/`, `Optimal Dispatch of FER/` | Dispatch of flexible resources (power-to-heat, power-to-gas) with an OPF controller / FMUs. |
| `pf_ninebus/` | A PowerFactory 9-bus system with flexible loads; needs a PowerFactory licence. |
| `scenarios/microgrid_scenario.yaml` | A minimal declarative scenario: `energysim run examples/scenarios/microgrid_scenario.yaml`. |

Each directory has its own README with the run command. The smoke test skips examples that need a proprietary engine
(PowerFactory, MATLAB / Octave) when it is not installed.

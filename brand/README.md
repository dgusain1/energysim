# energysim Brand Kit & Visual Identity

Welcome to the official **energysim** brand assets repository. This folder contains vector SVGs, high-resolution PNGs, favicons, and social preview assets for presentations, academic papers, documentation, and web integrations.

---

## 🎨 Palette & Color Specifications

The `energysim` brand identity reflects the convergence of multi-energy sectors:

| Energy Vector / Element | Color Name | Hex Code (Light) | Hex Code (Dark) |
|---|---|---|---|
| **Electricity & Power Flow** | Electric Violet / Purple | `#7c3aed` | `#a78bfa` |
| **Renewables, H2 & PtX** | Cyan / Teal | `#0d9488` | `#2dd4bf` |
| **Thermal / Heat / Gas** | Rose / Coral Orange | `#f43f5e` | `#fb7185` |
| **Primary Typography** | Slate Dark / Light | `#0f172a` | `#f8fafc` |

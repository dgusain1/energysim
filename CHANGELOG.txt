# Changelog - energysim

## 3.0.0 (unreleased, 3.0.0.dev0)

Major release with breaking changes.

### Breaking changes
- **Rollback and iterative coupling removed**: `coupling='iterative'`, `max_iterations`,
  `convergence_tolerance` and `save_state()` / `restore_state()` are gone. Use `'jacobi'`
  (default) or `'gauss-seidel'`, a smaller `t_macro`, or merge tightly coupled components.
  Algebraic loops use a one-macro-step delay. `bisect=True` on triggers raises
  `NotImplementedError` for the same reason.
- **Results API**: `simulate()` returns a `Results` object (`res['sim.var']`, `to_frame()`,
  `summary()`, `kpis()`, `save()`, `dashboard()`); `world.last_results` holds the last run.
  `res_filename` and the HDF5 helpers were removed; `out_dir` / CLI `--out` persist runs as
  Parquet/CSV + `meta.json` + `scenario.yaml`. Every simulator gets a final row at `stop_time`.
- **Strict units and the default unit system**: unknown units and incompatible dimensions raise
  `ValueError`; `energysim.units` is the single source of truth (`UnitSystem.default()` /
  `si()` / overrides; `energysim.utils` unit helpers delegate to it). Every connected variable is
  resolved: simulator `units` / `power_unit` (power-like names) -> component `units` -> connection
  `from_unit`/`to_unit` -> name suffix -> unit-system default by quantity -> unspecified. Values
  are converted into the receiver's unit; unspecified ends are never scaled (warning), or raise
  with `world(unit_policy='strict')`. `world(power_unit=...)` now defaults to `None` (the unit
  system's active-power unit). Visible via logs, `world.unit_table()`, `world.connection_units()`,
  `validate()`, `energysim units`, `run/validate -v`, `Results.units` and dashboard labels.
- **Safe mode and safe expressions**: signal strings / YAML conditions are parsed with a
  whitelisted AST evaluator (never `eval`); dotted-import model references need
  `allow_import=True`; `from_yaml(..., safe=True)` / `--safe` refuse code-executing simulator
  types, dotted imports and pickle model files.
- **Adapters / base**: `ConnectionError` renamed `ConnectionSpecError` (alias kept);
  `configure()` and `SET_PARAMS_BEFORE_INIT` lifecycle; runs are re-runnable;
  `set_parameters()` values apply at the start of every run.
- **World split**: `world.py` is now a thin class composed of mixins in `energysim._world`
  (registry, connections, units, coupling, events, runner, validation, scenario). The public
  `from energysim import world, World` is unchanged.
- `Sweep` was rewritten on top of the new `Ensemble` package.

### New
- **Event-driven / variable macro step** (predictive, no rollback): `t_macro` is the maximum
  step, `t_macro_min` (default `t_macro`: fixed step, bit-identical to 2.x) lets adapter hints
  (`max_step(t)`, `next_event_time(t)`) shrink it. `world.schedule(t, action)` lands steps
  exactly on event times; `world.add_trigger(name, condition, action, direction)` fires on
  threshold crossings at step boundaries; YAML `events:` / `triggers:` (declarative `set` only);
  fired events in `Results.meta['events']`. Hints: signal breakpoints, CSV `align_to_rows`,
  FMU ME `nextEventTime`, `ModelComponent.time_to_event()` (OCGT/CCGT timers, BESS / flow
  battery / H2 tank / thermal tank limits, PEM fuel-cell ramps). Adapters do a shorter final
  micro-step (`step_partial`) when a macro interval is not a multiple of their step size.
- Ensemble package (samplers, `Ensemble` / `EnsembleResults`, `NoisyInput`), control layer
  (`energysim.control`: MPC, OPF, PyPSA rolling horizon), network-lite heat/gas networks,
  validation suite and generated docs (units, validation).
- Worlds (with connections) are deep-copyable and picklable.

## 2.1.9.1
- **Brand & Visual Identity**:
  - Integrated official brand kit with scalable SVGs for light and dark modes (`brand/`, `docs/assets/brand/`, `.github/assets/`).
  - Added responsive logo banners in `README.md` and documentation header.
  - Added vector favicons, standard multi-resolution `.ico`, and Apple touch icons.
  - Added 1280x640 OpenGraph social preview cards for GitHub and web embedding.
- **Python Compatibility & Modernization**:
  - Modernized codebase with `__future__.annotations` and compatibility across Python 3.10 through 3.14+.
  - Added GitHub Actions CI matrix testing across Python versions.
  - Configured ReadTheDocs build using `.readthedocs.yaml` with MkDocs Material.

## 2.1.9
- **Physical Multi-Energy Component Library**:
  - Added native physics models for Green Hydrogen & PtX (`PEMElectrolyzer`, `AlkalineElectrolyzer`, `SOECElectrolyzer`, `H2Compressor`, `H2StorageTank` 350-bar real gas, `FuelCell_PEM`, `FuelCell_SOFC`, `MethanationReactor`).
  - Added Storage models (`BatteryBESS` with Thevenin ECM + thermal + aging, `FlowBattery` VRFB, `Flywheel`).
  - Added Turbomachinery & Thermal models (`CombinedCycle_CCGT`, `GasTurbine_OCGT` with cold/warm/hot timers, `CHP_SteamTurbine`, `ReciprocatingGenset`).
  - Added Renewables & Heating/Cooling (`PhysicsPV`, `WindTurbine`, `SolarThermalCollector`, `IndustrialHeatPump`, `ElectricBoiler`, `Chillers`, `CarbonCapture_Amine`).
  - Added pre-parameterized OEM equipment catalog (`catalog.Tesla_Megapack_2XL`, `catalog.Nel_A1000`, `catalog.GE_7HA_02`, `catalog.ITM_Power_Trident`, etc.).
- **Vectorized Fleet Simulation**:
  - Introduced high-performance SIMD/NumPy vectorized containers (`StorageFleet`, `PVFleet`, `BuildingFleet`).
- **Co-Simulation Adapters**:
  - Pandapower adapter supporting AC/DC power flow and Optimal Power Flow (OPF).
  - PyPSA adapter for online single-snapshot dispatch.
  - OpenDSS distribution system adapter via `OpenDSSDirect.py`.
  - DIgSILENT PowerFactory adapter via Python API.
  - FMU (FMI 1.0/2.0 Co-Simulation & Model Exchange) adapter.
  - MATLAB & GNU Octave auto-detecting adapters.
- **Core Orchestrator (`world`)**:
  - Dependency resolution via directed acyclic graph topological sorting.
  - Automatic physical unit conversions and scaling (MW, kW, W, kg/s, Nm³/h, bar).
  - State snapshotting (`save_state()` / `restore_state()`) for iterative coupling.
- **CLI & Declarative Scenarios**:
  - Added `energysim` CLI entry point for executing declarative YAML simulation scenarios.
- **Documentation**:
  - Full documentation rewrite built with MkDocs Material, interactive case studies, and notebook gallery.

## 2.1.8

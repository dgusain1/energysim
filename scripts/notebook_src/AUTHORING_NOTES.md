# Notebook authoring notes (energysim)

Sources are percent-format `.py` files in this directory, named `NN_slug.py`; `python scripts/build_notebooks.py --check` syntax-checks them and `python scripts/build_notebooks.py NN` writes `examples/notebooks/NN_slug.ipynb` (see the docstring of `scripts/build_notebooks.py`: `# %% [markdown]` cells use `# ` prefixed lines, `#@include snippets/x.py` inlines shared code).
**Never execute notebooks or run full simulations** (the maintainer does that). You may import and instantiate a class / call `step` once in a scratch script to catch crashes. Use absolute paths; do not `cd` into subfolders permanently.

## Rules for every notebook
- Self-contained, unexecuted, deterministic (`np.random.default_rng(seed)`), < ~60 s runtime, each cell < 180 s. Use real narrative markdown: goal, physics/equations, what to look at, caveats ("illustrative parameters, replace with datasheet/test data"). No manufacturer brand numbers.
- First code cell: imports incl. `from IPython.display import display`, `import matplotlib.pyplot as plt`, `from energysim import world`.
- `tests/docs/test_notebooks.py` executes every notebook; optional deps (pypsa, opendssdirect, fmpy, oct2py + Octave, pandapower) must be guarded: `try: import x; HAS_X=True / except ImportError: HAS_X=False`, and dependent cells wrapped in `if HAS_X:` with a printed skip message. FMU only if `"win64"`-style platform is in `fmpy.supported_platforms(path)`. Octave only if `oct2py` imports AND `oct2py.Oct2Py()` starts (try/except).
- Include a short "Where to go next" markdown cell and link neighbouring notebooks.
- Plots: matplotlib only, labelled axes with units, `plt.tight_layout(); plt.show()`.

## API facts (verified from source)
**World**: `world(start_time=0, stop_time=..., t_macro=900, power_unit="kW"|None, coupling="jacobi", unit_policy="lenient"|"strict", seed=None)`. `res = sim.simulate(pbar=False)` returns `Results`: `res["sim.var"]` -> Series indexed by time [s]; `res["sim"]` -> DataFrame; `res.to_frame()`; `res.units`; `sim.last_results` also works. Engine is fast (a year at hourly macro step with a 120-unit fleet < 1 s). Macro exchange is Jacobi: feedback loops have one macro step delay (warns; fine). `sim.get_adapter(name)` returns the adapter (fleet states survive after the run: `adapter.states['soc']`). `sim.get_model(name)` returns the pandapower net / pypsa net.
**Signals**: `sim.add_signal("name", callable_or_number, step_size=900, units={"y": "kW"})`, single output `y`, callable returns a number. Connect `{"name.y": "target.var"}`; fan-out: value is a list `["a.x","b.y"]`; fan-in (sum): key is a tuple `("a.p","b.p"): "c.p"`. Values are converted into the receiver's unit when both ends have resolved units (suffix `_kw/_mw/_degc/_kwh/_pu`, `power_unit=`, `units={}`, component `units` dict). Declare units for every connected custom variable (class attr `units = {...}` on the fleet/model, or `units=` in the add call) to avoid "unspecified" warnings.
**Models** (`from energysim.models import ...`, `ModelComponent` subclasses; add with `sim.add_model("n", model=obj, step_size=60, outputs=[...])`):
BatteryBESS in P_cmd[MW, +charge], T_amb; out P_actual, SoC, T_batt, SOH, V_terminal, I_current, Q_heat_kW; params capacity_mwh, p_max_mw, soc_init, soc_min, soc_max, nominal_voltage_v, c_th_kj_k, r_th_k_w, t_init_c, ocv_curve, rin_curve, inverter_curve, calendar_fade_pct_per_year_25c, cycle_life_to_eol, eol_fade. Its default maths: OCV = V_nom*Curve1D(soc,[0,.05,.1,.2,.4,.6,.8,.9,.95,1] -> [.85,.92,.95,.98,.99,1,1.02,1.05,1.07,1.10]); Rin = r_base*mult, r_base=(V_nom*0.03)/(p_max_mw*1e6/V_nom), mult at soc [0,.1,.2,.5,.8,.9,1] = [3,1.8,1.2,1,1,1.2,1.5]; inverter eff vs load ratio [0,.05,.1,.2,.5,.75,1] = [.80,.88,.93,.96,.975,.97,.96]; Rint solve Rin*I^2+Voc*I-P_dc=0; SoC integrates Voc*I; thermal C dT/dt = I^2 Rin - (T-Tamb)/Rth; SOH loses Arrhenius calendar + cycle fade (source: src/energysim/models/storage.py).
IndustrialHeatPump in Q_heat_cmd_MW, T_source, T_sink; out P_elec_MW, Q_heat_MW, COP. ThermalStorageTank in Q_cmd_MW; out Q_actual_MW, SoC. ElectricBoiler in P_cmd[MW]; out P_actual, Q_thermal_MW. PhysicsPV in G_poa[W/m2], T_amb, v_wind, curtail_limit[MW]; out P_ac, P_dc, T_cell. WindTurbine in v_wind, T_amb; out P_actual[MW]. CombinedCycle_CCGT / GasTurbine_OCGT in P_cmd[MW], T_amb; out P_actual, fuel_consumption_MMBtu_hr (unit MMBtu/h converts to MW automatically; 1 MMBtu/h = 0.29307 MW), CO2_emissions_t_hr, state. AlkalineElectrolyzer/PEMElectrolyzer in P_cmd[MW]; out P_actual, m_dot_H2_kg_hr. H2Compressor, H2StorageTank in m_dot_in_kg_hr, m_dot_out_kg_hr; out pressure_bar, mass_stored_kg, SoC.
`Curve1D(x, y, min_val=, max_val=)` is callable with arrays; `Surface2D(x, y, z)` with `z.shape == (len(x), len(y))` is now callable with arrays too (`s(x_array, y_array)`; added in this change). Both in `energysim.models.common`.
**Custom ModelComponent**: subclass, `register_variables(inputs=[...], outputs=[...], defaults={...})`, `register_parameters(...)`, class attr `units`, implement `step_model(dt, time)` reading `self._inputs_val[...]`, writing `self._outputs_val[...]`; must be quiescent at dt=0.
**Fleets** (`from energysim.container import VectorizedContainerAdapter, BatteryFleetAdapter, PVFleetAdapter, BuildingFleetAdapter, VectorizedFunctionAdapter`): subclass `VectorizedContainerAdapter`: `super().__init__(name=, size=, step_size=)`; per-unit parameters are plain NumPy arrays (use `self._as_vector(x, "label")`); `self.register_state("soc", init)`, `self.register_input("t_amb_degc", default)`, `self.register_alias(...)`; implement `step(self, time, step_size=None)` using `dt = step_size or self.step_size`, read inputs from `self.input_values[...]`, write states with `self.states[k][:] = ...`. Inputs accept a scalar (broadcast) or an N-vector. Outputs: every state/input `v` also as `total_v`, `mean_v`, `min_v`, `max_v`, `v[i]`. Add: `sim.add_fleet(sim_name="fleet", container=obj, step_size=300, outputs=["total_p_kw", "mean_soc"], units={...})` (the fleet's own step_size is overwritten by the `step_size` argument; default 900). A class attr `units = {"var": "unit"}` is honoured. Built-ins: BatteryFleetAdapter(size, capacity_kwh, max_charge_kw, max_discharge_kw, initial_soc, soc_min, soc_max, efficiency): in p_cmd_kw (+charge); out soc, actual_p_kw, loss_kw. PVFleetAdapter(size, peak_kw): in irradiance_w_m2, t_ambient; out p_kw. BuildingFleetAdapter(c_th_kwh_per_k, r_th_k_per_kw): in t_ambient, q_heat_kw, q_solar_kw; out t_indoor. `add_fleet(fleet_type='battery'|'pv'|'building', size=..., ...)` also works.
**Controllers**: `from energysim.control import RuleController`; `RuleController(rule, measurement_inputs=[...], setpoint_outputs=[...], units={...}, initial_measurements={...}, initial_setpoints={...}, step_size=900)` where `rule(t, meas, forecasts) -> dict` of setpoint values; add with `sim.add_model("ctrl", ctrl, step_size=900)`; outputs also `solver_status` etc. Decisions act one macro step later.
**Networks** (`from energysim.networks import HeatNetwork, GasNetwork`, scipy needed): `add_producer(name, capacity, cost=0, carrier_efficiency=1)`, `add_consumer(name, demand=0)` (serving order = insertion order under scarcity), `add_storage(name, capacity_mwh, p_max, soc_init)`, `add_pipe(a, b, capacity, loss_pct=0, delay_s=0, linepack_capacity_mwh=0 [gas])`. Add `sim.add_model("dh", model=net, step_size=900)`. Variables: `<producer>.available_MW|cost|dispatch_MW`, `<consumer>.demand_MW|delivered_MW|unserved_MW`, `<storage>.p_cmd_MW|soc`, `<a>-<b>.flow_MW|loss_MW|utilization|linepack_MWh|pressure_bar`, `total_supply_MW|total_demand_MW|total_unserved_MW|total_losses_MW`, heat: `<consumer>.supply_T_C`, `mean_supply_T`.
**pandapower** (`sim.add_powerflow("grid", model=net, inputs=[...], outputs=[...], step_size=900)`): variables are `"<element name>.<column>"` for ANY named element (`load`, `sgen`, `gen`, `storage`, `ext_grid`, `line`, `trafo`, `bus`); every load/sgen/gen/ext_grid/bus must have a unique non-empty `name`. Inputs e.g. `"L1.p_mw"`, `"PV1.p_mw"`; outputs e.g. `"Bus 3.vm_pu"`, `"Line 2.loading_percent"`, `"T1.loading_percent"`, `"Grid.p_mw"`, `"L1.p_mw"`. Native unit MW (pandapower sgen p_mw positive = generation). Pass a freshly built net per world (the adapter keeps it).
**OpenDSS** (`sim.add_opendss("feeder", model="path/Master.dss", inputs=["Load.l1.kW"], outputs=["Bus.n2.vm_pu", "Line.l1.p_kw", "Circuit.losses_kw"], step_size=900)`): write the DSS script to a temp dir from the notebook; process-wide singleton (one circuit; create worlds sequentially). Inputs `Type.Name.Property` (kW in, kW out). Voltage bases must be set in the script (`Set voltagebases=[...]`, `CalcVoltageBases`).
**PyPSA** (`sim.add_pypsa("net", model=n, inputs=["ld.P"], outputs=["b1.V","g0.P","l01.loading_percent"])`): single-snapshot power flow; inputs `P`/`Q` of generators/loads/storage units; a generator with control Slack ignores p_set.
**MATLAB/Octave** (`sim.add_matlab("fname", model="<dir containing fname.m>", inputs=[...], outputs=[...], engine="octave", step_size=900)`): `.m` file must be a FUNCTION `function [o1,o2] = fname(i1,i2,time)`; `time` is appended automatically; use `persistent` state and derive dt from consecutive calls (see examples/matlab_cosim/models/thermal_mass.m).
**FMU** (`sim.add_fmu("p2g", model="path.fmu", step_size=1, inputs=[...], outputs=[...], validate=False)`): repo FMUs `examples/optimal_dispatch/Hydrogen.ptg_modelB_case2.fmu` (inputs P_order [MW], T_ambient, gas_demand, ptg_switch=1; useful outputs electrolyser_detailed1.Pelec [=P_order], electrolyser_detailed1.nH2 [~0.00085 at 10 MW, ~0.0024 at 30 MW, unit undeclared], electrolyser_detailed1.electrochemical.efficiency2 [~0.77 -> 0.72], storage2.S_storage, controller_P2G3.Pmin/Pmax, lcoh.cost) and `P2H.pth_modelB_case2.fmu` (inputs P_order, T_ambient, heat_demand, pth_switch; outputs hp2.Pelec, hp2.COP, hp2.Q, storage.S, controller_APL.Pmin/Pmax, lcodh.cost). Windows-64 binaries only; FMU variables carry no units -> connect with explicit `units=`/`from_unit`. Use `record_all=False`.
**Ensembles**: `from energysim import Ensemble; from energysim.ensemble import Grid, Scenarios`; `Ensemble(factory(params, seed) -> world, sampler=Grid({...}) , kpis={"name": lambda r: float(...)}, keep="kpis").run()`, then `.kpis()` DataFrame, `.params`. KPI lambdas receive `Results`.
**Units table**: kW<->MW, MMBtu/h->MW, degC<->K all auto-convert. Unit suffix names: `_kw`, `_mw`, `_kwh`, `_degc`, `_pu`, `_w_m2`.

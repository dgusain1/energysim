- YAML `type: model` now instantiates components: `model: PEMElectrolyzer` (any class exported by `energysim.models` / `energysim.networks`), a catalog archetype (`model: BESS_4h_2MW`) or `model: path/file.py:Class` (not in safe mode), with constructor parameters under `parameters:` / `options:`. Known components round-trip through `to_dict()` / `to_yaml()` when their constructor parameters can be recovered; other in-memory models are skipped with a warning.
- Units used by the component models but missing from the registry are registered: `W/m2` (irradiance, accepts `kW/m2`), `m/s` (wind speed, accepts `km/h`, `kn`, `mph`), `MMBtu/h` and `MMBtu` (fuel energy flow / energy, 293.07107 kW per MMBtu/h). A test asserts that every unit declared by a model or network class is known.
- Signals that return more than one value are rejected when added (`add_signal`, YAML): "signals expose a single output 'y'; add one signal per output". A callable returning a one-element list still works.
- PyPSA adapter: the `P` / `Q` of a slack generator without `p_set` (NaN in PyPSA) falls back to the bus balance, so it is always available.
- Scheduled / triggered declarative `set` actions on a connected input are now held for the step in which they fire (the exchange skips that input once) instead of being overwritten by the exchange of the same step.
- `Results.summary()` returns a purely numeric frame (`min, max, mean, last, count`; `last` is NaN for non-numeric variables) so `.round()` and `.loc[row, ['min', 'max']]` work; units and dtypes are in the new `Results.describe_variables()`.

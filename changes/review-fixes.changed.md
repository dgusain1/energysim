- `simulate()` now defaults to `record_all=False` (one row per macro step) instead of recording every micro step, which was surprising for long runs with fine micro steps. Use `record_all=True`, `options({'record_all': True})`, the YAML `world: {record_all: true}` key or `energysim run --record-all` for micro-step recording.
- Safe mode (`from_yaml` / `from_dict` with `safe=True`, CLI `--safe`) is hardened: FMUs (native code) are refused unless `allow_native=True` / `--allow-native`; `type: model` with `file.py:Class` is refused; every model / csv / script / option file path and the scenario's `out_dir` must resolve (symlinks and `..` included) inside the scenario directory tree. The threat model is documented in `docs/safe-mode.md` and `SECURITY.md`.
- Stale examples and docs: the custom-adapter notebook no longer mentions `save_state` / `restore_state`; the industrial BTM example and notebook use the generic `BESS_2h_2MW` archetype instead of a deprecated branded alias; example READMEs no longer mention `es_res.h5`; legacy `pf=` keywords in examples were replaced by `mode='ac'`.
